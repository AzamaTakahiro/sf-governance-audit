# \# GovGate — Salesforce 内部統制・商談監査ログオートメーションパッケージ

# 

# J-SOX監査対応および内部統制要件を満たす、商談変更差分のイミュータブル（変更不可）記録リファレンスアーキテクチャ。

# 

# \## 概要

# 全項目ロギングのノイズ破綻を防ぎ、統制上クリティカルな4項目に絞った高視認性監査ログ基盤。

# 

# \## 対象統制項目

# | 項目名 | API名 | データ型 | 統制上の位置づけ |

# | :--- | :--- | :--- | :--- |

# | 商談名 | `Name` | テキスト | 案件の特定・改ざん検知 |

# | 金額 | `Amount` | 通貨 | 値引き・承認バイパス検知 |

# | 完了予定日 | `CloseDate` | 日付 | 期ズレ・期末売上操作の検知 |

# | ステージ | `StageName` | 選択リスト | 営業プロセス逸脱・逆戻り検知 |

# 

# \## 技術仕様

# \- \*\*ログ保存先\*\*: カスタムオブジェクト `GovernanceAuditLog\_\_c` (`TargetRecordId\_\_c` によるトレーサビリティ確保)

# \- \*\*差分抽出ロジック\*\*: `ISCHANGED()` と `BR()` 関数を組み合わせた縦並びノイズレスUI

# \- \*\*設計思想\*\*: 変更のない項目や同値変異ノイズを排し、監査人の視認負荷を極小化
